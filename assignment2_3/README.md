# 第二题第（3）问：汇报与作业材料

## 下载与使用

在仓库首页点击绿色 **Code → Download ZIP**，解压后进入 `assignment2_3` 文件夹。
也可下载本目录中的 `presentation_materials.zip`，解压后使用。

1. 阅读 `01_上台操作步骤.docx`，按步骤在学校电脑准备和运行。
2. 阅读 `02_逐行讲解与演讲稿.docx`，理解配套 48 行 R 代码并练习汇报。
3. 把 `03_作业报告_第二题第三问.docx` 交给组长整合；补充姓名、组别和日期。
4. 使用 `04_课堂汇报.pptx` 演示；每页备注区包含讲解提示。

## 运行准备

本目录未上传老师的原始数据。请把你电脑上已有的 `MA_parcels_sample.parquet` 复制到本目录，与 `question2_3.R` 放在一起。

RStudio 打开 `question2_3.R`，选择 **Session → Set Working Directory → To Source File Location**。
首次缺包时运行 `source("install.R")`，然后点击 **Source** 执行分析。
图表与摘要保存到 `results` 文件夹，已有图片是实际运行的结果。

Word 报告只覆盖你负责的第二题第三小问，并不替代整个小组报告。

请按课程要求及实际情况说明辅助工具的使用。
